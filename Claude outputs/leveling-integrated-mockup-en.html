What this page is

Today the leveling line's data lives in three places that never meet: the ERP work order (coil ID, customer, spec, weight — MariaDB erp_data), the PLC log (cut length, stroke cycle time, inverter load, every ~2 seconds — MariaDB LEVELING_DATA), and the tension controller readings captured by camera + AI every 2–5 minutes (Supabase ai_tension_readings). This page joins them: ERP↔PLC by coil ID, and tension↔coil by time (a reading is attributed to whichever coil the PLC says was running at that moment), then turns the joined data into plain-language insights.
  • Audience: office PC — managers and the CEO. Wide layout, no login (public static HTML under public/, linked from a 연구실 Lab card).
  • Data sources: existing leveler-explore Edge Function modes (leveling_date, leveling_stroke_overview, leveling_stroke_detail, leveling_rhythm) + Supabase anon read of ai_tension_readings. No new tables. One small new mode ("per-coil run start/end for a date") may be added for the timeline.
  • All numbers below are today's real values (2026-09-03, KST) shown as a static mockup. Purple annotation boxes explain each block and are not part of the final page.

Timeline — the join mechanism. Each coil that ran today becomes a purple bar from its first to last RUN=1 timestamp. Each tension reading is a dot at captured_at. A dot inside a bar is attributed to that coil; a dot outside any bar is labelled "before run / between coils". Hovering a dot shows the reading; hovering a bar shows the coil's ERP spec. This is how the page links tension data to coils without changing the OCR script or the database — later, if the script starts storing COIL_ID directly, the page uses that instead and the time rule becomes a fallback.

Process rhythm. Uses the existing leveling_rhythm mode: RUN=1 rows bucketed into 1–10 min windows (adaptive to run length), averaging CYCLETM and INVERTERSPEEDPER. Red windows are buckets whose cycle time exceeds mean + 1σ; a load drop in the same window suggests a feed stall or manual pause rather than a heavier cut. Flat segments (4+ identical buckets) are flagged as a possible PLC value freeze, as the mode already does.

  • ×

    Only 11 distinct coil IDs across 186,050 LEVELING_DATA rows. Today is tagged correctly.
Insight rules (phase 1). All derived from data already available, no AI call:
1) Spec match: thickness_um vs ERP spec thickness ×1000.
2) Setting change during run: consecutive readings differ in tension_set/thickness_um while PLC RUN=1.
3) Slow windows: rhythm buckets above mean+1σ; severity raised if inverter load also drops.
4) Finish estimate: sheet weight = thickness × width × cut length × 7.85 g/cm³; remaining sheets × avg cycle.
5) Data-quality warnings: failed/stale tension readings, missing COIL_ID, PLC silence > 3 min while ERP says "in progress".
Phase 2 (once several coils accumulate): compare this coil's cycle time and tension set against previous coils of the same spec, and flag "slower than usual" or "unusual tension for this thickness".
