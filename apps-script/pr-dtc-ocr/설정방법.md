# 구글 OCR 판독 설정 방법 (PR-DTC-3100, 2026-11-27)

판독 PC가 찍은 텐션 컨트롤러 사진을 **내 구글 계정의 Apps Script**로 보내 글자를 읽습니다.
대시보드(연구실 > PR-DTC-3100 실시간 인식)의 **판독 방식** 버튼으로 Groq / 구글 OCR / 둘 다를 고릅니다.

## A. Apps Script 만들기 (구글 계정, 약 5분)

1. https://script.google.com 접속 → **새 프로젝트** → 이름: `PR-DTC OCR`
2. 왼쪽 **서비스 +** → **Drive API** 선택, 버전 **v3**, 식별자 **Drive** → 추가
3. 왼쪽 톱니바퀴(프로젝트 설정)
   - 시간대: **(GMT+09:00) 서울**
   - 맨 아래 **스크립트 속성 추가**: 속성 `OCR_KEY`, 값 = 비밀키(영문·숫자 30자 정도, 판독 PC에도 똑같이 넣음)
4. 편집기의 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs`를 붙여넣기 → 저장
5. 위쪽 함수 선택에서 **authTest** → **실행** → 권한 검토 → 계정 선택 → (확인되지 않은 앱 경고 시) 고급 → 이동 → 허용
   - 실행 로그에 `권한 OK`, `OCR_KEY 설정됨: true`가 나오면 성공
6. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** (판독 PC가 로그인 없이 호출해야 하므로. 비밀키가 맞아야만 동작)
   - 배포 → **웹 앱 URL**(…/exec) 복사
7. 확인: 웹 앱 URL을 브라우저로 열어 `{"ok":true,"service":"pr-dtc-ocr",...}`가 나오면 정상

코드를 고치면 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** (URL은 그대로 유지됨)

## B. 판독 PC 설정 (C:\OCR APP)

1. 지금 쓰는 `ocr_monitor_production.py`를 `ocr_monitor_production_backup_1127.py`로 복사해 둠
2. 새 `ocr_monitor_production.py`로 바꿔 넣음
3. `ocr_monitor_secrets.local.bat`을 메모장으로 열어 아래 두 줄 추가 (따옴표 없이)
   ```
   set GOOGLE_OCR_URL=https://script.google.com/macros/s/.../exec
   set GOOGLE_OCR_KEY=(A-3에서 정한 비밀키)
   ```
4. 시험 1회 (명령 프롬프트에서 C:\OCR APP 로 이동 후):
   ```
   call ocr_monitor_secrets.local.bat
   python ocr_monitor_production.py --source "http://<폰 IP>:8080/video" --test --engine both
   ```
   - `[구글 원문 …ms]` 아래에 화면 글자가, `[구글 분리 결과] 6개: …`가 나오면 성공
   - 원문은 복사해서 전달해 주세요 (항목 분리 규칙을 실제 화면에 맞추는 데 필요)
5. 실행 중인 판독 프로그램 창을 닫고 `run_ocr_monitor.bat` 다시 실행 (감시 프로그램이 2분 안에 자동으로 켜기도 함)
6. 대시보드에서 **판독 방식 → 둘 다 (비교)**, **인식 주기 → 5분** 선택

## C. 항목 분리 규칙 다듬기 (필요할 때)

구글은 글자만 돌려주므로 `parse_google_text()`가 라벨(OUT, THICK, T.SET, RATIO 등)과 단위(%, V, um, mm)로 6개 값을 나눕니다.
실제 화면 글자가 다르면 판독 PC의 같은 폴더에 `google_ocr_labels.json`을 만들어 라벨만 바꿀 수 있습니다 (프로그램 수정 불필요, 다음 주기부터 반영):
```json
{ "tension_set": ["T\\.?\\s*SET", "장력\\s*설정"], "tension_rate": ["RATIO", "장력율"] }
```
- 6개 중 4개 이상 읽고 허용 범위 안이어야 '판독 성공'으로 저장됩니다.
- 허용 범위: 출력% 0–100, 전압 0–30, 두께 100–6000um, 시작경 100–3000mm, 장력설정·장력율 0–100

## 한도·비용
- 구글: 무료. 개인 계정은 문서 변환 하루 약 200~250건 → 테스트 중 5분 주기(4시간 48건, 둘 다 모드도 구글은 48건)
- 둘 다 모드는 Groq도 같이 호출하므로 Groq 한도는 지금과 같음
